PoC 4 · Fake Download QR

The QR encodes a URL to a themed download page. On scan, the victim’s browser loads the page and auto-triggers a download of Crypto.com-Desktop-Setup.exe (a harmless placeholder here).

Landing page

How it works. The QR points to download.html which fetches malware.exe as a Blob and forces a save via <a download>. The browser saves it under the attacker-chosen filename regardless of the served MIME type or path, so malware.exe can be renamed to any plausible installer name in one edit.

Replace the payload. Overwrite malware.exe in the working directory with any test artefact — e.g. the EICAR AV test string or a benign signed binary — to demonstrate real AV/EDR detection.
